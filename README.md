# 🧭 رحلة ابن بطوطة — تحفة النظار في غرائب الأمصار وعجائب الأسفار

عرض كامل ومتصفّح لكتاب **«تحفة النظار في غرائب الأمصار وعجائب الأسفار»** — رحلة ابن بطوطة،
أملاها على **محمد بن جزي الكلبي** (ت 779هـ / 1377م).

## 📌 حول المشروع
- **النص الكامل** للكتاب: مقدمة ابن جزي + رحلة ابن بطوطة كاملة في **٧٤ باباً**،
  من طنجة وحجّه وإلى الصين، وعودته إلى المغرب، وانتهاءً بخاتمة ابن جزي.
- المصدر: **المكتبة الشاملة — كتاب ١٢٠٠٩** (طبعة دار الشرق العربي، مجلدان).
- لا يُضاف أي نص غير الموجود في المصدر؛ تُعرض الفقرات كما هي في الطبعة.

## ✨ المزايا
- 🔎 **بحث فوري** في الكتاب كله: تُلوَّن النتائج **بالأخضر** مع **عدّاد** وتنقّل بين المواضع (▲/▼).
- 🔎 بحث داخل الفصل الحالي مع نفس المزايا.
- 🌗 **وضع نهاري/ليلي** محفوظ محلياً.
- 🔤 تكبير/تصغير خط النص.
- 📋 نسخ نص الفصل.
- 📖 تذكّر آخر باب قُرئ + «متابعة القراءة».
- 📴 **يعمل دون اتصال** (Service Worker + `manifest.json` = PWA قابلة للتثبيت).

## 📂 هيكل الملفات

```
├─ index.html            ← الواجهة والتصميم
├─ style.css             ← الأنماط
├─ app.js                ← القراءة والبحث
├─ sw.js                 ← التخزين دون اتصال
├─ manifest.json         ← PWA
├─ data/chapters.json    ← نص الكتاب الكامل
├─ icon.svg              ← أيقونة متجهة (بوصلة رحلة)
├─ icon-192.png          ← أيقونة التطبيق
├─ icon-512.png          ← أيقونة التطبيق
└─ tools/render_icons.mjs← توليد الأيقونات
```

## 🚀 النشر على GitHub Pages

1. أنشئ مستودعاً باسم `rihlat-ibn-battuta` (Public) مع إضافة README.
2. ارفع ملفات المشروع كما هي.
3. فعّل GitHub Pages من **Settings → Pages → Source: `main` → `/root`**.
4. انتظر ١–٣ دقائق.
